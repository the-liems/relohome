## Proposed demo narrative

The demo should follow a person relocating: state a move goal, compare housing, select a destination, obtain moving and travel options, inspect the combined plan, approve each paid step, and see progress and the final result or recovery path. The [open graph-demo issue](https://github.com/AI20K-Build-Phase-Cohort-4/P-044/issues/21) currently targets Location, Moving within one city, Flight, and mock Payment. The team still needs to select the exact demo request and verify the full flow. Present these as product features only after they work in the deployed demo.

An illustrative opening request is: “I am moving to [destination] around [date]. Find housing within [budget], work out how to move my belongings and travel there, then show me the options and ask before booking anything.” Replace the bracketed values with a tested scenario before recording a demo. Show where the selected housing address enters the moving quote, which searches can run in parallel, and how the customer sees current prices and approvals.
